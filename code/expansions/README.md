# Proposed Expansions — Mechanism Analyses (run side-by-side with training)

These analyses sharpen **where and how** the heterogeneity advantage arises. They need **only existing
checkpoints/caches (no GPU, no retraining)**, so they run in parallel with the Colab fixed-τ training.
Full rationale + paper links: `Mechanism Avenues.md` in this folder (copy of the canonical
`Project Files/Explanation files/New Quantification Avenues — Mechanism of the Heterogeneity Advantage.md`).

## Notebook manifest

| Notebook | Avenue | What it produces | Inputs (existing) |
|---|---|---|---|
| `A1 — Tau-Resolved Single-Neuron Function.ipynb` | **A1** | per-neuron τ vs task-MI / rate / coded axis (language·parity) → division of temporal labour | `repr_seed*_het.npz`, checkpoint `network.0.beta` |
| `A3 — Causal Tau Shuffle, Transplant, Dose-Response.ipynb` | **A3** | accuracy under τ-permute, τ-transplant (hom←het), and a het→hom **dose–response** spread sweep | checkpoints + SHD test set (forward pass) |
| `A4 — Intrinsic (Functional) Timescales.ipynb` | **A4** | spike-autocorrelation τ_intrinsic vs imposed τ_mem — does diversity survive recurrence? | 4 ms `spk_cache/*.npy`, checkpoint `beta` |
| `B1 — Target-Aware PID (unique-redundant-synergy).ipynb` | **B1** | Williams–Beer PID of neuron pairs about the class → is het's edge in **unique** info (breadth)? | `repr_seed*_*.npz` |
| `B3 — Task-Subspace Alignment.ipynb` | **B3** | how many PCs each task axis needs (language/parity/XOR), het vs hom | `repr_seed*_*.npz` |

**Priority:** A3 (cleanest causal diversity-vs-longτ test, no retrain) and A1 (most direct "where").
B1/B3 deepen the information/geometry story; A4 validates the premise.

**How to run each:** open the notebook, confirm the `PROJECT_ROOT` in the first config cell, **Run all**.
Each writes a figure to `Project Files/Explanation files/figures/` and a records `.json` next to itself.
The `.ipynb` files are generated by the `_build_*.py` scripts in this folder (repo convention); edit the
builder and re-run it to regenerate a notebook.

> **Environment note.** On this Windows setup, `matplotlib + torch + sklearn` in one process segfaults
> (OpenMP clash — the repo's own scripts avoid that trio). A1 and B3 were therefore written **sklearn-free**
> (numpy MI / numpy SVD). A3 uses `MAX_TRIALS=768` to cap the CPU forward passes for a fast directional read
> — set it to `None` in the config cell for the full test set before quoting final paired statistics.

## Executed — first-run results (2026-07-03)

All notebooks were run locally on the existing caches/checkpoints. Headlines:

- **A1** (563 active het neurons, 10 seeds): τ↔function gradient is **weak/near-null** here — log τ vs
  task-MI r=−0.03 (n.s.); parity-coding neurons sit at slightly higher median τ (27.6 vs 20.2 ms) but n.s.
  (p=0.39). *So a simple "slow=parity, fast=language" split is not strongly present in the rate code* —
  worth re-checking on the τ_intrinsic axis (A4) and per-time-bin rather than trial-mean rate.
- **A4** (functional timescales): **premise validated** — het log τ_mem ↔ log τ_intrinsic **r=+0.25,
  p=3.4e-9** (imposed diversity is expressed in the dynamics); het functional-timescale spread wider than
  hom (std log₁₀ 0.39 vs 0.27), median 95 vs 67 ms.
- **B1** (target PID, per pair): atoms are **comparable, slightly lower for het** per pair (unique Δ=−0.008,
  p=0.32; synergy Δ=−0.005, p=0.084). Since het has ~2.8× more active neurons, *population-level* unique
  info can still exceed hom's — the per-pair notebook does not capture that breadth; add a population/summed
  read to test the breadth hypothesis directly.
- **B3** (task-subspace): **het spreads task axes over more PCs** — participation ratio 6.53 vs 5.31; PCs to
  reach 80% of the coding vector: language 7 vs 4, XOR 5 vs 3 (parity 3 vs 3). Consistent with het's
  functional dimensionality living in the task-relevant directions.
- **Ablation** (het, largest/smallest/random-τ-first): **seed-dependent, no clean universal long-τ effect**
  (at 50% ablated, largest-first drops more in some seeds, smallest-first in others). Averages lean toward
  small-τ removal hurting slightly more — i.e. accuracy is spread across the τ range rather than carried by
  the long tail alone. Read alongside the fixed-τ ladder before drawing conclusions.
- **A3** (causal τ interventions) ★: **the strongest result.** τ-**shuffle** collapses het 0.685 → 0.304
  (Δ=−0.38, p<0.001); **transplant** of het-τ onto hom *hurts* (0.563 → 0.322, p<0.001); **dose–response**
  is monotone (0.32 → 0.36 → 0.46 → 0.59 → 0.69 as spread rises). ⇒ diversity is **co-adapted with the
  weights and load-bearing**, not just a good marginal set of timescales. (Capped eval `MAX_TRIALS=768`.)
